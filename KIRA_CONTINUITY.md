# Kira continuity reference

## Approved identity

Use the owner-approved illustrated Kira look already present in reviewed VideoExpress outputs: a single 2D character with an ivory oval face, dark hair in one bun, small simple eyes, thin dark line-art limbs, navy jacket, cyan center detail, and stepped gold lapel accent. Keep the visual language flat 2D / stickman-inspired with restrained navy, cream, cyan, and gold. Do not switch to photoreal humans, anime, 3D, or a second design system.

The current project's master-reference binding has been inconsistent. A character description is not equivalent to a bound image reference. Record the exact selected reference ID when verified; otherwise mark reference lock UNVERIFIED and compare every rendered clip against approved Kira footage.

## Set and prop locks

- Payday desk: navy desk, cream ledger, one gold coin token, navy lamp, neutral cream wall.
- Calendar: plain calendar with no generated writing; use clean blank pages and add dates in editing only after checking the narration.
- Category tray: exactly four distinct trays; no pseudo-text. Add labels in editing.
- Buffer: one small reserve jar and gold tokens; keep token counts stable within a shot.
- Debt and bills: cream paper cards with simple icons, no fake account details or legible generated amounts.
- Closing staircase: navy foundation, gold steps, one clear gold arrow only when the narration supports it.

## Motion contract

For each shot record the incoming Kira pose, one action, outgoing pose, prop changes, camera side, and the next shot's start. Keep one Kira unless a second figure has an explicit scripted role. Reject duplicate bodies, face/hand morphing, unexpected props, unexplained set flips, frame-edge ambiguities, and visible gibberish.
